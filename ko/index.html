DBGridy
Windows용 데이터베이스 에디터

SQL·NoSQL 데이터 편집부터 SSH·SFTP까지 하나의 앱에서

DBGridy는 MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, SQLite, Microsoft SQL Server, Oracle을 지원하는 Windows용 데이터베이스 에디터입니다.

SQL·NoSQL 데이터를 엑셀처럼 그리드에서 편집하고, 쿼리를 실행하며, CSV·SQL·JSON으로 내보낼 수 있습니다.

SSH 터미널, SFTP 파일 전송, WSL 접근 기능을 제공합니다. 독점 라이선스에 따라 개인·교육·사내 업무 용도로 무료 사용이 가능합니다.

지금 다운로드

DBGridy 주요 기능

🔌 멀티 데이터베이스 지원

즐겨 사용하는 다양한 데이터베이스를 하나의 통합 인터페이스에서 원활하게 연결하고 관리하세요.

MySQL MongoDB Redis ClickHouse PostgreSQL SQLite Microsoft SQL Server (MS-SQL) Oracle

📊 그리드 기반 편집

사용자 친화적인 그리드 인터페이스에서 데이터베이스 레코드를 직접 편집하세요. 마치 엑셀을 다루듯 편리한 데이터 관리를 경험할 수 있습니다.

📝 고급 쿼리 에디터

SQL 및 JSON을 위한 문법 강조 기능(Syntax Highlighting)을 지원합니다. 멀티 탭 기능을 통해 여러 작업을 동시에 처리하고, 대량 데이터 작업 도구도 활용해보세요.

🎨 시각화 및 테마

내장된 JSON Pretty-print, 스키마 및 Redis 키를 위한 시각적 트리 뷰(Tree View), 그리고 눈이 편안한 라이트/다크 테마를 모두 지원합니다.

💾 데이터 관리

CSV, SQL, JSON 형식으로 데이터를 손쉽게 내보낼 수 있습니다. Blob 데이터를 Hex로 변환하는 등의 유용한 도구들도 포함되어 있습니다.

🚀 네이티브 성능

윈도우 네이티브(WinForms) 애플리케이션으로 제작되어 최고의 성능과 시스템 통합성을 보장합니다.

🔐 SSH/SFTP & WSL 지원

SSH 터미널로 원격 서버에 접속하고, SFTP로 파일을 탐색 및 전송하며, WSL 환경에도 직접 접근할 수 있습니다.

자주 묻는 질문

DBGridy는 무엇인가요?

DBGridy는 MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, SQLite, Microsoft SQL Server, Oracle을 지원하는 Windows용 데이터베이스 에디터입니다. 그리드 데이터 편집, 쿼리 실행, SSH·SFTP·WSL 접근을 하나의 데스크톱 앱에서 제공합니다.

어떤 데이터베이스를 지원하나요?

MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, SQLite, Microsoft SQL Server(MS-SQL), Oracle을 지원합니다.

회사에서도 무료로 사용할 수 있나요?

조직 규모와 관계없이 개인·교육·사내 업무 용도로 무료 사용이 가능합니다. DBGridy는 독점 소프트웨어이며 재배포, 재판매, 수정 및 서비스형 제공은 금지됩니다. 자세한 조건은 전체 라이선스를 확인해 주세요.

macOS나 Linux에서도 실행되나요?

DBGridy는 WinForms 기반의 Windows 네이티브 데스크톱 앱입니다. 다운로드는 Windows용이며, WSL 환경 접근은 Windows 앱 안에서 제공합니다.

어디에서 다운로드할 수 있나요?

공식 GitHub 릴리스 페이지에서 Windows용 DBGridy를 다운로드하세요. README와 선택한 릴리스의 안내를 확인해 주세요.

SSH와 SFTP 기능도 있나요?

네. SSH 터미널, SFTP 파일 탐색·전송 및 WSL 환경 접근 기능을 제공합니다.
