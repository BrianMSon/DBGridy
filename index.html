SQL, NoSQL, SSH and SFTP in one desktop application

DBGridy is a Windows database editor for MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, SQLite, Microsoft SQL Server and Oracle.

Edit SQL and NoSQL records in an Excel-like grid, run queries, and export data to CSV, SQL or JSON.

DBGridy Features

🔌 Multi-Database Support

Seamlessly connect to your favorite databases in one unified interface.

MySQL MongoDB Redis ClickHouse PostgreSQL SQLite Microsoft SQL Server (MS-SQL) Oracle

📊 Grid-Based Editing

Edit database records directly within a user-friendly grid interface. Experience Excel-like convenience for your data.

📝 Advanced Query Editor

Syntax highlighting for SQL and JSON. Multiple query tabs for multitasking and bulk operations tools.

🎨 Visualization & Themes

Built-in JSON pretty-printing, visual Tree Views for schemas/Redis keys, and support for both Light and Dark themes.

💾 Data Management

Export data to CSV, SQL, or JSON easily. Includes handy tools like Blob-to-Hex conversion.

🚀 Native Performance

Built as a native Windows (WinForms) application for maximum performance and system integration.

🔐 SSH/SFTP & WSL Support

Connect to remote servers via SSH terminal, browse and transfer files with SFTP, and access WSL environments directly from the app.

Frequently Asked Questions

What is DBGridy?

DBGridy is a Windows database editor for MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, SQLite, Microsoft SQL Server and Oracle. It combines grid-based data editing, queries, SSH, SFTP and WSL access in one desktop application.

Which databases does DBGridy support?

DBGridy supports MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, SQLite, Microsoft SQL Server (MS-SQL) and Oracle.

Is DBGridy free for business use?

Personal, educational and internal business use is free, including use in organizations of any size. DBGridy is proprietary software. Redistribution, resale, modification and offering it as a service are prohibited. Read the full license for the terms.

Does DBGridy run on macOS or Linux?

DBGridy is a native Windows desktop application built with WinForms. The downloads are for Windows; WSL access is provided from within the Windows application.

Where can I download DBGridy?

Use the official GitHub releases page to download DBGridy for Windows. Follow the README and the instructions for your selected release.

Does DBGridy include SSH and SFTP?

Yes. DBGridy includes an SSH terminal, SFTP file browsing and transfers, and access to WSL environments.
