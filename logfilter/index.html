04 BUILT FOR FOCUS

      

        
01
메인 화면은 멈추지 않게
파일 읽기와 검색은 Web Worker가 맡습니다. 분석 중에도 버튼과 스크롤은 자연스럽게 반응합니다.

        
02
수백만 줄은 가볍게
전체 문장을 DOM에 쌓지 않습니다. 압축된 위치 인덱스와 가상 스크롤로 현재 화면만 가져옵니다.

        
03
같은 원인은 한눈에
변하는 시간·ID·숫자를 접어 반복 메시지를 모읍니다. 빈도가 높은 장애 원인을 먼저 확인하세요.

        
04
완전한 로컬 처리
업로드 서버와 계정이 없습니다. 선택한 로그는 현재 브라우저 안에서만 읽고 분석합니다.
